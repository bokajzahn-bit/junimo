Privacy Policy

This policy covers the application "Junimo Studio", a private tool used only by the owner of the YouTube channel Junimo.

What the app accesses

  • The owner's own YouTube channel, to upload and schedule videos and edit their titles and descriptions (YouTube Data API).
  • The channel's own analytics, such as views and watch time per video (YouTube Analytics API).
  • Public comments on the channel's own videos, to read them and post replies as the channel.

How data is used and stored

  • Data is used only to run the owner's own channel. It is not sold, shared with third parties or used for advertising.
  • Access tokens and data are stored only on the owner's private computer. Nothing is stored on servers operated by this app.
  • The app does not create profiles of viewers or commenters. Comment text is processed only to decide on and write a reply.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

This app uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

Data deletion

The app stores tokens and channel data only locally. The owner can delete all stored data at any time by deleting the app's data folder. Data received from the YouTube API Services is not kept longer than needed: analytics and comment data are refreshed or deleted within 30 days.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions or via the Google security settings. Stored data is deleted within 30 days after access is revoked.

Contact the owner through the Junimo channel page on YouTube or via github.com/bokajzahn-bit.
